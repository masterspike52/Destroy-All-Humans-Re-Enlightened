About
---------------------------------------
Overhaul mod for 2008's Destroy All Humans: Path of the Furon. Features improved graphics, dozens of bug fixes, and overhauled gameplay.

**Requirements**

* U.S. Xbox 360 Path of the Furon ISO
* TFC Installer
* Xenia Canary or ReDAHM, the Path of the Furon static recomp

**Important**

Requires a modified executable to run. Use the included tool to modify your executable (see Instructions.txt for additional info).

**Commonly Asked Questions**
---------------------------------------

1. Is this playable on ReDAHM?

Yes. It is compatible with both the emulated version on Xenia Canary or our static recomp ReDAHM.

2. I'm stuck on the loading screen, what do I do?

It should fix itself if you're playing on ReDAHM. If you're playing Xenia Canary, do the following steps:

* Press down twice
* Press A
* Press down once
* Press A

If done correctly, the game should boot into the extras menu.

3. Is it playable on Steam Deck?

Yes.

4. The game crashes when I use the black hole gun. Is this normal?
<br>
Yes. The black hole gun has a chance of crashing the game. Tread carefully.
